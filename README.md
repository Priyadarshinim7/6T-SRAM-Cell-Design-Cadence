# 6T SRAM Cell Design and Physical Implementation Using Cadence EDA Tools

# Project Overview
This project focuses on the transistor-level design, simulation, and physical implementation of a 6-Transistor (6T) Static Random Access Memory (SRAM) cell using Cadence EDA tools.
The 6T SRAM cell consists of two cross-coupled CMOS inverters for data storage and two NMOS access transistors controlled by the Word Line (WL). The design was verified through DC and transient simulations to evaluate its stability, data retention, and read/write functionality.
The project was further extended to synthesis and physical implementation using Cadence Genus and the associated Cadence design flow.

# Objectives
- Design a functional 6T SRAM bitcell at the transistor level.
- Verify the Voltage Transfer Characteristics (VTC) and butterfly curve.
- Analyze Static Noise Margin (SNM) and data retention.
- Validate read and write operations through transient simulation
- Implement the full-custom layout using Cadence Virtuoso.
- Extend the design flow to synthesis and physical implementation.
- Understand the complete VLSI design flow from circuit design to physical implementation.

# 6T SRAM Cell Architecture

A conventional 6T SRAM bitcell consists of:

- **Two PMOS Pull-Up Transistors:** Provide the load for the storage nodes.
- **Two NMOS Pull-Down Transistors:** Form the driving network of the cross-coupled inverters.
- **Two NMOS Access Transistors:** Connect the internal storage nodes to the bitlines during read and write operations.

### Internal Signals

| Signal | Description |

| Q |      First internal storage node |
| QB |     Complementary storage node |
| WL |     Word Line; controls access transistors |
| BL |     Bit Line |
| BLB |    Complementary Bit Line |
| VDD |    Supply voltage |
| VSS |    Ground |

The cross-coupled inverter configuration creates a bistable latch that stores one bit of information as long as the supply voltage is maintained.

# Transistor Sizing
The transistor dimensions used in the project are:
| Transistor | Type | Width (W) | Length (L) |

| PM0, PM1 | PMOS Pull-Up | 4 µm | 180 nm |
| NM0, NM1 | NMOS Pull-Down | 2 µm | 180 nm |
| NM2 | NMOS Access | 1 µm | 180 nm |

**Supply Voltage:** 1.8 V

The transistor sizing was selected to balance read stability, write-ability, and data retention.
The pull-down NMOS transistors are stronger than the access transistors to reduce read disturbance, while the access transistors provide sufficient drive strength for writing new data.

## 📊 Simulation Results

### DC Analysis — Butterfly Curve

The DC analysis demonstrates the Voltage Transfer Characteristics of the cross-coupled inverters.
Key observations:

- Both inverters exhibit switching transitions near the midpoint voltage.
- The output logic levels approach 0 V and 1.8 V.
- The butterfly curve exhibits symmetric characteristics.
- The cell demonstrates stable data retention under hold conditions.

### Transient Analysis — Read and Write Operations
Transient analysis verifies the dynamic behavior of the SRAM cell.

**Write Operation:**

When the wordline is asserted high, the access transistors connect the internal storage nodes to the bitlines. Complementary bitline values force the cell to store the desired logic state.

**Hold Operation:**

When the wordline is low, the access transistors are turned off. The cross-coupled inverters maintain the stored data.

**Read Operation:**

When the wordline is asserted high with precharged bitlines, the stored data is reflected on the bitlines through the access transistors.
The simulation verifies the functionality of the SRAM cell during the access cycles.
